# Orderly — Frontend

Responsive order management dashboard. Create orders, track their status, and move them
through confirmation, shipment, and cancellation with real-time stats.

## Development

```bash
npm install
npm run start
```

Starts the dev server at http://localhost:4200. API calls are proxied to the backend during
development (see `proxy.conf.json`).

## Build

```bash
npm run build
```

Produces a production bundle in `dist/`.
